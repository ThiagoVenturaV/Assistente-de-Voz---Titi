# Landing page do Titi

Página pública da versão beta do assistente local Titi.

## Desenvolvimento

```bash
npm install
npm run dev
```

Validação:

```bash
npm run build
node --test tests/rendered-html.test.mjs
```

O botão principal aponta para o instalador `Titi-Setup-0.1.0.exe` publicado na versão `v0.1.0-beta` do GitHub Releases.
