# Identidade visual do Titi

O nome da marca é **Titi**. O ícone principal é a cabeça frontal do gato-robô, derivada do mascote animado.

## Sistema de marca

- **Ícone:** use a cabeça isolada em superfícies de sistema e interface, como executável, instalador, favicon, cabeçalho, avatar e miniaturas.
- **Mascote completo:** reserve o corpo animado para momentos em que o Titi aparece como personagem, reage ou comunica um estado.
- **Nome:** mantenha sempre a grafia `Titi`; o ícone pode acompanhar o nome, mas não o substitui em apresentações formais.
- **Área de proteção:** preserve espaço transparente ao redor das orelhas e dos módulos laterais; não recorte a cabeça.
- **Fundo:** prefira carvão, creme ou superfícies neutras com contraste suficiente.

## Paleta principal

- Carvão: `#30383A`
- Azul quase preto: `#06181C`
- Creme: `#F6E7BF`
- Turquesa: `#39D7CB`
- Menta: `#74DEB1`

`titi-head-master.png` é o ativo mestre. Execute `python scripts/build-icon.py` para derivar os tamanhos usados pelo aplicativo e pela landing page.
